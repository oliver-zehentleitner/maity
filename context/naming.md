# Naming

## The project is called Maity

**Id:** b69961bd-0e74-4fa8-8a14-0740dda97c3c
**Type:** decision
**Status:** active
**Evidence:** confirmed
**Source:** naming conversation with the maintainer, 2026-10-21

The project, its repository, its package name and its domains (maity.dev,
maity.team) are "Maity": a coined word that reads like *matey* — a mate, a
team member — with "ai" inside it. It is not a person's name and has no
prior meaning in software. The package name was free on PyPI and npm at the
time of the decision; the GitHub search noise from "Maity" being a common
surname was accepted deliberately, because whoever searches for the
project by name will find it anyway.

**Reason:** the hub's premise is that agents become members of a team, so
the name should say *companion*, not *command*, and stay neutral towards
how a team is organised. The maintainer wanted a coined word rather than a
plain-English phrase, with a nod to AI in the spelling rather than in the
meaning.

**Rejected alternative:** the first choice of the day, a group word for a
small flock of birds. Dropped within the hour because an active,
self-hosted agent platform in the neighbouring category already carries
that name, with its own domain and plugin ecosystem — same name, same
niche, not recoverable. A second bird-flock word turned out to be taken by
a Claude Code fleet dashboard in the same way. The check that caught both
— GitHub repositories, not only package indexes and domains — is the one
to run for every future name.

**Rejected alternative:** "Fleet Commander" / "Fleet Control". A
chain-of-command tone that contradicts the idea that the organisation
model is a configurable profile (hierarchical, decentral, autonomous), and
a collision with an established IDE brand.

**Rejected alternative:** names built on "flight" or "airport" as a vehicle
for the letters "ai". The aviation image was only ever a vehicle, and the
maintainer did not want the project tied to it.

**Rejected alternative:** a name already carried by a software company in
the maintainer's region (trademark risk), and a "genie" metaphor — a
servant that grants wishes is the opposite of a team member, and "genie"
is taken everywhere.

**Rejected alternative:** plain-English phrase names in the style of the
maintainer's other projects. Maity is a separate project and does not need
to match that style.

**Rejected alternative:** spelling variants. "Maighty" reads as *mighty*
and like a typo, with two pronunciations; "Maithy" loses the *mate*
reading; "Maite" is a given name and taken on PyPI; "Maiti" loses the
reading and every domain was taken.
