# Security

## Reporting a vulnerability

Please report security problems privately, by email to
[info@maity.team](mailto:info@maity.team) (or
[info@maity.dev](mailto:info@maity.dev); both reach the maintainer).
Do not open a public issue, pull request or discussion for a
vulnerability.

Include what you can of:

- the component (hub, CLI, runner, dashboard, the Helm chart or the
  container image) and the version or commit;
- what an attacker can do, and under which conditions (which role, which
  credential, which network position);
- steps to reproduce, or a proof of concept;
- whether the problem is already public or known to others.

Please keep the details private until a fix is released.

## Supported versions

Maity has no release yet. Security fixes go to `main`.
