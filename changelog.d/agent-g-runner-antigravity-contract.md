### Added

- Contract: the runner harness `antigravity` (Google's Antigravity CLI, `agy`; §15.3, not built). Its confinement is `allowlist`: agy's own permission rules, with its terminal sandbox around every other command. Because agy loads the hooks, MCP servers, plugins and rules of the directory it starts in, the runner starts it in a workspace folder per placement that holds the clone as `repo` and nothing else (§15.5), and refuses a start when the folder holds anything more (`workspace_in_use`, new detail `workspace_not_bare`, §15.7). The runner writes the session settings before every launch: the default agent mode (not `auto`), commands in the sandbox without asking, the sandbox on, the folder trusted, `.git/maity` denied to the file tools, `maity` and the repository's grants allowed. They are merged with the agy settings of the user the agents run as. Both modes; a run continues with `-c`, per workspace folder. Local mode has no `antigravity`.
