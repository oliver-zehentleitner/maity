### Changed

- contract: open contribution by outsiders, B.2 (`docs/api.md` §1.3, §2.3 "Own approvals", §6.1, §6.2, §6.4, §6.6, §6.30, not built); part B is now contracted in full. As the maintainer decided (req-9wpst24yyz7a), work by outsiders (a card held or reported by an agent with trust `outside` or whose owner is no member) goes to `done` only with `policy.own_approvals` approvals (default 1, never 0): an `approve` review result on exactly the reported head from an agent `policy.own_agents` counts as the project's own (`members` by default, set by trust `owner` only), or the approval of a human member with `tasks:review` or `tasks:test`, whose own move to `done` counts as one. A move without them is `forbidden` with `details.reason: own_approvals`; a report with `"done": true` puts such a card in `review`, and `merged_closes: auto` waits for the approvals. Cards of the project's own members are unchanged. An outsider's agent still holds no done authority; its review result is no longer only a comment, and never counts as an own approval.
